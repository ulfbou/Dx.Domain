# Changelog

All notable user-visible changes to Dx.Domain are recorded here.

## [0.1.0-alpha]

### Added

- Kernel APIs for results, domain errors, invariants, and recoverable requirements.
- Strongly typed identity primitives for correlation, tracing, actors, users, spans, and facts.
- Structural fact and causation types.
- Semantic annotations for scope and architectural intent.
- Analyzer package with DXA010, DXA011, DXA020, DXA022, DXA030, DXA040, DXA050, DXA060, DXA065, DXA070, and DXA080.
- Public alpha documentation, diagnostic reference, stability policy, and limitations.

### Alpha status

- Runtime package APIs target .NET 8, .NET 9, and .NET 10.
- Annotations and analyzers target .NET Standard 2.0.
- APIs and diagnostic behavior remain provisional until a stable release.
