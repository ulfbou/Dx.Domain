# Contributing to Dx.Domain

1. Read the [architecture](docs/understand/architecture.md), [non-goals](docs/understand/non-goals.md), and [limitations](docs/use/limitations.md).
2. Keep changes focused and follow [Conventional Commits](docs/contribute/conventional_commits.md).
3. Run the canonical [local validation sequence](docs/contribute/local-validation.md).
4. Record user-visible, stability, and documentation effects in the pull request.

Report vulnerabilities through [SECURITY.md](SECURITY.md), not through public issues or pull requests.
