# DXK001 — Assembly Role Required
**Intent**: Architectural identity must be explicit.  
**Applies to**: Consumer assemblies.  
**Never applies to**: Kernel/Primitives/Annotations.  
**Classification**: `[assembly: DxAssemblyRole(...)]`, DXT role map.  
**Examples**: ✅ `Contracts.Billing` declares Contracts; ❌ missing role attribute.  
**Remediation**: Add a single role attribute; split aggregates if needed.
