# DXA010 — Construction Discipline (Facade)
**Intent**: Centralize creation of domain types behind an approved boundary (facade/factory).  
**Applies to**: Consumers only.  
**Never applies to**: Kernel/Primitives/Annotations/tests/attributes/exceptions/result infra/assembly metadata.  
**Classification**: Object creation and factory invocations; allowlists via attributes/config.  
**Remediation**: Use/introduce approved facade methods; make direct constructors internal.
