# DXA065: Unresolved XML Documentation Reference

**Status:** Shipped in `0.1.0-alpha`
**Diagnostic ID:** DXA065
**Default severity:** Warning
**Category:** `Documentation`
**Enabled by default:** true
**Implementation scope:** S0 public API

DXA065 reports plain references to recognized Dx.Domain types in XML documentation where a `see` or `seealso` element with `cref` can provide compiler-resolved, rename-safe documentation.

## Remediation

Replace the plain type name with the appropriate XML documentation element and a resolvable `cref` target.

## Limits

The analyzer covers recognized type names in supported documentation nodes. It does not prove general documentation completeness or correctness. Standard compiler suppression mechanisms remain technically available; repository policy determines whether suppression is accepted.

See the [canonical public reference](../public/reference/diagnostics/DXA065.md).
