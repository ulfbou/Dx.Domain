# DXA060: Forbidden Vocabulary in Kernel

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Error
**Category:** `Domain.Architecture`
**Mechanism:** Analyzer-enforced

## Trigger

Flags configured semantic vocabulary in classified kernel symbols.

## Remediation

Move semantic concepts to an edge or use a mechanical name when accurate.

## Limits

This is a naming heuristic, not semantic proof. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.
