# DXA065: Unresolved XML documentation reference

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Documentation`
**Mechanism:** Analyzer-enforced

## Trigger

Flags plain references to known Dx.Domain types in XML documentation.

## Remediation

Use a `see` or `seealso` element with `cref` so the compiler can resolve the symbol.

## Limits

Only recognized documentation and known type names are covered. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.
