# Dx.Domain 0.1.0-alpha

## Purpose

The first alpha establishes a small, compiler-assisted substrate for explicit invariants, results, errors, identities, and structural facts.

## Packages

- `Dx.Domain.Kernel`
- `Dx.Domain.Primitives`
- `Dx.Domain.Facts`
- `Dx.Domain.Annotations`
- `Dx.Domain.Analyzers`

Runtime packages target .NET 8, .NET 9, and .NET 10. Annotations and analyzers target .NET Standard 2.0.

## Included capabilities

- Result and domain-error values
- Runtime invariant and requirement mechanisms
- Strongly typed identity primitives
- Structural fact and causation types
- Semantic annotations
- Shipped diagnostics: DXA010, DXA011, DXA020, DXA022, DXA030, DXA040, DXA050, DXA060, DXA065, DXA070, and DXA080

## Important limitations

APIs and analyzer behavior are provisional. Static analysis does not cover reflection, serializer materialization, dynamic invocation, unchecked assemblies, or business-semantic correctness. DXA090 is planned and is not included.

## Adoption guidance

Install `Dx.Domain.Analyzers` explicitly, test installation in a clean project, review all diagnostics, and read the [stability](../stability.md), [limitations](../limitations.md), and [security](../security.md) pages before production use.
