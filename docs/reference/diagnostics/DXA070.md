# DXA070: Generated Code Tagging

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Domain.CodeGeneration`
**Mechanism:** Analyzer-enforced

## Trigger

Flags generated code missing an approved generated-code marker.

## Remediation

Add the supported generated-code attribute or marker in the generator output.

## Limits

Detection improves analyzer accuracy but does not validate generated behavior. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.
