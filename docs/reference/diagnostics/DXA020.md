# DXA020: Result Ignored

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Error
**Category:** `Domain.ResultHandling`
**Mechanism:** Analyzer-enforced

## Trigger

Flags a Result value that is produced and directly ignored.

## Remediation

Return, map, bind, match, or pass it to an approved terminal handler.

## Limits

Later correctness and transitive handling are not proven. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.
