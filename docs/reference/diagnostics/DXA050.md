# DXA050: Temporal Helper Usage in Kernel

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Domain.Architecture`
**Mechanism:** Analyzer-enforced

## Trigger

Flags temporal or policy-sensitive helpers in classified kernel code.

## Remediation

Move time policy to an edge or use the approved controlled source.

## Limits

Wrapped time access and code outside scope may not be detected. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.

## Examples

Bad:

```csharp
var now = DateTimeOffset.Now;
```

Good:

```csharp
var now = DomainTime.Now();
```

The example demonstrates the intended source shape. Validate the exact diagnostic against the installed alpha analyzer.
