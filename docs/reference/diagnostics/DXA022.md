# DXA022: Discouraged Domain Control Exception

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Domain.ExceptionHandling`
**Mechanism:** Analyzer-enforced

## Trigger

Flags common domain-control exceptions in Result-returning methods.

## Remediation

Return a failed Result for expected domain outcomes.

## Limits

Unexpected faults and conservative classification may remain unreported. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.

## Examples

Bad:

```csharp
throw new InvalidOrderStateException();
```

Good:

```csharp
return Dx.Result.Failure<Order>(error);
```

The example demonstrates the intended source shape. Validate the exact diagnostic against the installed alpha analyzer.
