# DXA030: Unapproved Handler Usage

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Domain.ResultHandling`
**Mechanism:** Analyzer-enforced

## Trigger

Flags a Result passed to a handler that is not recognized as approved.

## Remediation

Use a known handler or classify the handler through supported configuration.

## Limits

Configuration and symbol indirection affect recognition. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.

## Examples

Bad:

```csharp
CustomSink.Consume(result);
```

Good:

```csharp
var response = result.Match(OnSuccess, OnFailure);
```

The example demonstrates the intended source shape. Validate the exact diagnostic against the installed alpha analyzer.
