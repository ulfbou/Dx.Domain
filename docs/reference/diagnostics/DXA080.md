# DXA080: Facade Invariant Enforcement Missing

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Warning
**Category:** `Domain.Architecture`
**Mechanism:** Analyzer-enforced

## Trigger

Flags classified facade factories without recognized invariant enforcement.

## Remediation

Validate inputs and return a failed Result or invoke the approved invariant mechanism.

## Limits

Presence of a check does not prove invariant completeness. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.

## Examples

Bad:

```csharp
public static Order Create(string id) => new(id);
```

Good:

```csharp
public static Result<Order> Create(string id) => Validate(id);
```

The example demonstrates the intended source shape. Validate the exact diagnostic against the installed alpha analyzer.
