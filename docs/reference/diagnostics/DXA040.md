# DXA040: Kernel Public Surface Freeze

**Status:** Shipped in `0.1.0-alpha`
**Default severity:** Error
**Category:** `Domain.Architecture`
**Mechanism:** Analyzer-enforced

## Trigger

Flags unapproved additions to the classified kernel public surface.

## Remediation

Remove the surface or complete the repository API and DPI approval process.

## Limits

Protection depends on correct kernel classification and baseline governance. Standard compiler suppression mechanisms are technically available; consuming repositories decide whether policy permits them.
