## [ADR-0015](../adr/adr-0015-dxa070-generated-code-tagging.md): [DXA070](../analyzers/dxa070.md) Generated Code Tagging

**Status:** Accepted  
**Date:** 2026-02-08

### Context
Generated code must be identifiable to analyzers.

### Decision
Implement [DXA070](../analyzers/dxa070.md) to enforce generated code tagging.

Triggers: Generated files without <auto-generated> or [GeneratedCode]
Severity: Info

---

### Enforcement Coverage
**Enforced by:** [DXA070](../analyzers/dxa070.md)

**Coverage Level:** **Infrastructure**

---

### Guarantee
Improves analyzer accuracy; reduces false positives.

### Consequences
Requires generator authors follow convention.

### DPI Alignment
Item 3 — increases compiler assistance.
