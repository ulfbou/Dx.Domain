## [ADR-0015](adr-0015-dxa070-generated-code-tagging.md): [DXA070](../../reference/diagnostics/DXA070.md) Generated Code Tagging

**Status:** Accepted  
**Date:** 2026-02-08

### Context
Generated code must be identifiable to analyzers.

### Decision
Implement [DXA070](../../reference/diagnostics/DXA070.md) to enforce generated code tagging.

Triggers: Generated files without `<auto-generated>` or `[GeneratedCode]`
Severity: Info

---

### Enforcement Coverage
**Enforced by:** [DXA070](../../reference/diagnostics/DXA070.md)

**Coverage Level (Historical):** Infrastructure (as recorded in 2026-02-08)

**Current Strength:** Weak — See [Dx.Domain Enforcement Specification](../enforcement-specification.md) for current authoritative classification.

---

### Decision intent and demonstrated boundary
Improves analyzer accuracy; reduces false positives by allowing other analyzers to skip generated code.

### Consequences
Requires generator authors follow convention; voluntary compliance improves system accuracy but cannot be mechanically enforced.

### DPI Alignment
Item 3 — increases compiler assistance.
