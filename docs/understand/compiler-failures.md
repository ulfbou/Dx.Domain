# From compiler output to corrective action

A DXA diagnostic identifies a constrained, statically observable pattern. It does not prove complete program correctness.

1. Open the matching page in the [diagnostic reference](../reference/diagnostics/index.md).
2. Confirm project scope and analyzer configuration.
3. Compare the observed pattern with the documented limits.
4. Apply the remediation and add a focused regression test.

Use [respond to diagnostics](../use/guides/respond-to-diagnostics.md) for the task workflow and the [enforcement model](enforcement-model.md) for guarantee boundaries.
