# Changelog

## [0.1.0-alpha] - 2026-05-08

### Added

- Fact<TPayload>
- Causation
- IDomainFact
- FactType
- TransitionResult<TState>
- DomainFactExtensions

### Notes
- This is an alpha release. APIs are functional but may evolve.
- All types are designed for immutable domain fact modeling with causation metadata.
- Breaking changes are unlikely but possible prior to 0.1.0 stable.
