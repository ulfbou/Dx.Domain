# Changelog

## [0.1.0-alpha] - 2026-05-08

### Added
- Initial alpha release
- AggregateRootAttribute, EntityAttribute, ValueObjectAttribute
- DomainEventAttribute, FactoryAttribute, IdentityAttribute
- InvariantAttribute, PolicyAttribute
- DxScopeAttribute, DxLayerAttribute, DxFacadeAttribute
- DxGeneratedAttribute, DxTemplateAttribute
- DxAssemblyRoleAttribute, DxApprovedHandlerAttribute
- ApprovedKernelApiAttribute, DpiJustifiedAttribute
- Scope enum, DxAssemblyRole enum
- DxCategories, DxRuleIds, DxSeverities

### Notes
- This is an alpha release. APIs are functional but may evolve.
- All attributes are designed for compile-time analysis only.
- Breaking changes are unlikely but possible prior to 0.1.0 stable.
